# 背书 · 原声背诵 App

个人背书工具，痛点：背古文（口诀、赋文、经文）需要**用自己的原声**反复听、逐句磨。

## 功能总表（已归集）

1. **单句循环**：一句一句反复听、不断背；手动点击切换下一句。
2. **文本定位**：页面显示全文，点哪一句，声音自动定位到哪一句。
3. **自我录制**：录自己的声音，用原声不断听、不断记忆。
4. **记忆算法与听写**：艾宾浩斯遗忘曲线安排复习；支持听写。
5. **录音归集**：逐句录音按篇归集连播，大段听（可调语速、句间留白）。
6. **奖励系统**：打卡、句量统计、徽章（v3）。
7. **PK 机制**：与人对战/排行（v3）。
8. **背诵语音识别打分**：背诵后语音识别与原文比对打分（v3）。

## 版本路线

### v1 播放器核心（当前）

- 导入文本（纯文本/Markdown 粘贴），自动分句（。！？；换行），分句结果可手工调整。
- 逐句录音：屏幕显示当前句 → 录 → 自动跳下句；单句可重录。
  - 录音页带全文句列表，点任意句直接跳转（重）录，不用逐句导航。
  - 录音中可「作废重录」：丢弃当前这条，立刻重新录同一句。
  - 自动跳下句后可一键「重录上一句」。
- 单句循环、点句定位、上一句/下一句。
- 录音归集连播：整篇顺序播放，语速 0.75–1.5×，句间留白 0–3 秒（留跟读时间），整篇循环。
- 选句连播：篇目页「☑ 选句」勾选任意句子集，连播/上下句只在所选句里走；不勾选即播全篇。
- 数据纯本地（IndexedDB），录音不出设备。

### v2 记忆系统

- 【已做】测验（Quiz）模式：篇目页「🧠 测验」进入，一题一题出。
  - 题型两种：听写（放自己的录音 → 默出原文）、接句（看上句 → 背出下一句）；无录音句自动退化为接句提示。
  - 每题：提示首字（可选）→ 显示答案 → 自评 记得/忘了；支持乱序出题。
  - 结束出成绩单（对/错、错句列表可点放录音），可只重测错句；上次成绩显示在篇目页。
- 【已做】艾宾浩斯复习队列（间隔：当天→1→2→4→7→15→30 天）：
  - 复习单位：整篇一张卡，长篇可在开启计划时点句分段，每段独立排期。
  - 入队：篇目页手动「开始背诵计划」（录音没录完也可以背）。
  - 复习动作 = 测验模式（听写/接句），结束逐句对错统计 → 整体自评（记住/模糊/忘了，按错误率标建议）。
  - 排期：记住升一级、模糊原级重复、忘了退两级（最低当天级）；到期卡片汇入首页「今日复习」队列，复习完可一键跳下一个到期。
- 【已做】打字默写逐字比对：测验里勾选「打字默写」，显示答案时按 LCS 逐字比对，打中绿、漏错红下划线，给出对字数统计（不打字则纯自评）。
- 【已做】整篇录制打点切分：录音页「🎬 整篇录制」一口气读完 → 播放中逐句「✂ 打点」（可回听、撤销）→ 自动切成逐句 WAV 覆盖保存。
- 【已做】导出合并音频：篇目页「⬇ 导出」，按句序合并已录句子（含当前句间留白设置）导出 WAV 文件。

- 【已做】背诵计时：测验/复习全程秒表计时（页面顶部实时显示），结束记录用时并与上一次同范围成绩对比（快/慢多少）；篇目页显示各范围（整篇/段/句区间）最近 6 次用时走势。复习卡历史同时记录用时。

v2 全部完成。

### v3 激励与评测

- 奖励系统：连续打卡、累计句数/篇数、徽章。
- PK 机制：好友对战或异步排行榜。**注意：需要后端与账号体系**，打破 v1/v2 纯本地边界，届时单独设计（最小方案：分数上传 + 排行，只传成绩不传录音）。
- 背诵语音识别打分：录背诵 → ASR 识别 → 与原文按编辑距离+完整度打分。**古文识别须用 Whisper 类大模型**（浏览器内置识别对文言文效果差）；可选端侧或 API，注意生僻字与异读字的容错表。

## 技术决定

- 平台：手机网页 PWA（可加到主屏幕）；后续需锁屏后台播放再考虑原生壳。
- 录音：逐句录制为主（每句一段音频，循环/定位/归集零对齐成本）。
- 听写批改：默认手写自评（古文打字成本高），打字比对可选。
- 存储：IndexedDB 纯本地；不做账号（直到 v3 PK）。
